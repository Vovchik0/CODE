# Зависимости Minecraft Load Tester
#
# Приложение работает как на PyQt5, так и на PyQt4 -- нужный биндинг выбирается
# автоматически (сначала PyQt5, затем PyQt4). Достаточно установить любой ОДИН
# из них.
#
# --- Рекомендуемый вариант: PyQt5 (ставится через pip на большинстве систем) ---
PyQt5>=5.12
#
# --- Устаревший вариант: PyQt4 ---
# PyQt4 снят с официальной поддержки и, как правило, НЕ ставится через pip.
# Если по каким-то причинам нужен именно он, установите системный пакет:
#   Debian/Ubuntu :  sudo apt-get install python3-pyqt4
#   Fedora        :  sudo dnf install PyQt4
#   macOS (brew)  :  brew install pyqt@4
#   Windows       :  неофициальные wheels PyQt4 под вашу версию Python
#
# Остальная функциональность использует только стандартную библиотеку Python
# (socket, threading, queue, json, csv, uuid, logging), дополнительные пакеты
# не требуются.
